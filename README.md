# Java Console Applications

This repository contains structured Java console-based systems developed as part of a focused software development internship.

## Projects Included

### 1. Freelance Invoice Generator
A console-based invoice system that:
- Accepts client details
- Calculates totals automatically
- Applies pricing logic
- Generates structured invoice output

Concepts Used:
- Methods and modular function design
- Conditional statements
- Loops
- Basic data formatting
- Clean program flow control

---

### 2. Movie Ticketing System
A console-based ticket booking simulation that:
- Displays movie options
- Handles seat selection logic
- Calculates ticket pricing
- Validates user input

Concepts Used:
- Arrays
- Conditional branching
- Loop control
- Input validation
- Structured problem-solving approach
